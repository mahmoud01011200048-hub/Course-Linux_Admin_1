# 🐧 Red Hat System Administration I (RH124) - Mastery & Presentation Decks

Welcome to my Linux Administration repository! This repository contains my customized, deep-dive presentation decks and study notes covering core **Red Hat Enterprise Linux (RHEL)** administration concepts.

## 📚 What This Repository Covers
- **Shell & CLI Basics:** Bash environment, command execution, and file system navigation.
- **File & Directory Operations:** File management, text editing, and I/O redirection.
- **User & Group Administration:** Account management, group permissions, and password policies.
- **Permissions & Security:** Standard Linux file permissions and access controls.
- **Process & Service Management:** Systemd services, daemons, and process monitoring.
- **Networking & Remote Access:** OpenSSH configuration, IP interface setup, and log inspection.
- **Storage & Package Management:** Disk management, mounting, and software installation via DNF/YUM.
